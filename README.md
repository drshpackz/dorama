# Дорама — плагин для Lampa

Плагин добавляет пункт **«Дорама»** в левое меню Lampa и открывает большую живую
ленту южнокорейского кино и сериалов из TMDB: все жанры (романтика, комедии,
драмы, экшен, исторические, фэнтези, мистика) плюс отдельные тематические
подборки — тёмные социальные триллеры (в духе «Паразитов», «Игры в кальмара»),
психологический хоррор и триллеры-головоломки. Сверху — **персональная лента
«Рекомендации для Вас»** по вашим лайкам с процентом совпадения, затем «Сейчас
смотрят», самое популярное и свежие новинки.

Лента **динамичная**: при каждом открытии ряды слегка обновляются (показывается
другая страница каталога), причём узор зависит от категории и ваших прошлых
оценок — так вы не видите одно и то же снова и снова.

> **Только корейский язык.** Все ряды отфильтрованы по `with_original_language=ko`,
> поэтому **японские тайтлы (например «Exit 8») не появятся** — это осознанный
> выбор каталога. Как включить японское/азиатское — см. «Как настроить выдачу».

## Установка

1. Откройте Lampa → **Настройки → Расширения** (Settings → Расширения).
2. Добавьте плагин по ссылке (raw URL):
   ```
   https://drshpackz.github.io/dorama/dorama.js
   ```
3. Перезапустите Lampa. В левом меню появится пункт **«Дорама»**.

## Что внутри

Один экран с рядами карточек (сериалы и фильмы), сверху вниз:

1. **Рекомендации для Вас** — персональные рекомендации по вашим лайкам/оценкам,
   с бейджем «Совпадение xx%».
2. Сейчас смотрят
3. Самые популярные: фильмы / Самые популярные: сериалы
4. Корейские новинки: сериалы / Корейские новинки: фильмы
5. Тёмные триллеры (исходные подборки): Корейские триллеры (сериалы), Корейское
   кино: триллеры, Социальные триллеры (неравенство), Выживание и антиутопия,
   Дом-ловушка (бетон / многоэтажка), Игры разума и саспенс, Лучшее: корейские
   триллеры.
6. Тематические: Психологический хоррор (сериалы / фильмы), Триллер-головоломка
   (сериалы), Триллер-головоломка: игра со зрителем (фильмы).
7. Жанровый каталог: Романтические дорамы, Корейские комедии, Korean drama:
   драмы, Боевики и экшен, Исторические фильмы (сагык), Фэнтези и мистика,
   Лучшее корейское кино, Лучшие корейские сериалы.
8. Сети и студии: Дорамы tvN / JTBC / SBS, Netflix Корея, Большое корейское кино
   (студии: CJ, Showbox, Lotte, Plus M, NEW).

**Персональный порядок ленты.** Ряды категорий (начиная с тёмных триллеров и ниже)
сортируются по вашим лайкам/реакциям: любимые жанры, сети и студии всплывают
наверх, нелюбимые опускаются. «Рекомендации», «Сейчас смотрят», популярное и
новинки всегда закреплены сверху. Без сигналов — порядок по умолчанию.

Карточки открывают обычную страницу деталей Lampa; у рядов-каталогов есть «ещё»
— полная сетка с бесконечной прокруткой (кроме ленты рекомендаций).

## Shorts

Пункт **Shorts** в левом меню (сразу под «Дорамой») открывает вертикальную
ленту коротких роликов из корейских фильмов и сериалов — как Shots в Lampa,
но отфильтровано под дорамы. Ролики берутся из публичной ленты CUB Shots и
сортируются: сначала корейские тайтлы, затем остальные азиатские (Япония,
Китай, Таиланд).
Управление: **↑/↓** (или свайп/колесо) — следующий/предыдущий ролик, **←/→** —
выбор на панели (постер / «Нравится» / «Позже» / «Меньше такого»), **OK** —
активировать выбранное (постер открывает карточку тайтла), **Назад** — выход.
Лента персональная: сначала ролики из тайтлов, которые вам нравятся (лайки и
реакции Lampa + «Нравится» прямо в ленте), затем корейские ролики ваших любимых
жанров, затем остальное; «Меньше такого» опускает тайтл и его жанры в самый
конец. Все сигналы хранятся локально.

## Лайки и рекомендации

- Нажмите и удерживайте **OK** на карточке → выберите **«Нравится»** (нативное
  избранное Lampa).
- Лайкнутые корейские/азиатские тайтлы становятся основой ленты **«Рекомендации
  для Вас»**. Плагин **обогащает** ваши лайки/реакции деталями TMDB (жанры, сеть,
  студия, теги) и собирает кандидатов из нескольких источников: TMDB-рекомендации
  и «похожие» по каждому лайку **плюс** подборки discover по вашим любимым жанрам,
  сетям, студиям и тегам. Чем больше совпадений по этим осям — тем выше тайтл.
- Оценка **строгая по вкусу**: только азиатское, только с совпадением по жанрам,
  вес рейтинга/популярности понижен, чтобы наверх не лезла попса. Топ — с бейджем
  **«Совпадение xx%»**. Уже лайкнутые/просмотренные исключаются, BL/gay и
  «не понравившиеся» (реакции 😴/💩 и их похожие) — тоже.
- Работает и по **реакциям** без нативных лайков: детали тайтла дают жанры/сети
  даже когда у реакции нет карточки.
- Пока лайков нет — в ряду показывается приглашение лайкнуть дорамы. Чем больше
  лайков, тем точнее рекомендации (обновляются при следующем открытии).

## Как настроить выдачу

Ряды лежат в `dorama.js`: `buildRows()` (исходные тёмные триллеры, не трогаются),
`popularRows()` («сейчас смотрят» + популярное), `buildExtraRows()` (тематические
+ жанровый каталог + сети/студии) и `buildDynamicRows()` (новинки на датах). Можно:

- **Расширить выдачу** — поднять/убрать `vote_count.gte` или убрать
  `with_keywords`.
- **Сменить тон** — поменять `with_genres` (помните: жанры **Триллер `53`** и
  **История `36`** существуют только для фильмов, не для сериалов `discover/tv`).
- **Включить японское/азиатское (в т.ч. «Exit 8»)** — в нужных рядах заменить
  `with_original_language=ko` на `with_original_language=ja|ko` (или
  `ko|ja|zh|th`). Рекомендации (`ASIAN_LANGS` в `dorama.js`) уже допускают
  `ja/zh/th`, так что лайкнутое японское и так попадёт в персональную ленту.
- **Сети/студии** — ряды задаются `with_networks=` / `with_companies=` (id TMDB):
  tvN `866`, JTBC `885`, SBS `156`, Netflix `213`, MBC `97`, KBS2 `342`; студии
  Showbox `3491`, CJ `7036`/`128404`, Lotte `7819`, Plus M `91505`, NEW `20064`.
- **Персональный порядок** — `orderCatalogRows` сортирует ряды по совпадению их
  жанров/сетей/студий/тегов с вашим вкусом; закреплённый верх = популярное+новинки
  (`pin`). Профиль вкуса строит `enrichSeeds` (детали лайков/реакций), он же питает
  мульти-источник рекомендаций (`facetTasks` в `loadRecommendations`).
- **Настроить динамику** — `rowPage(...)` задаёт ротацию страниц; глубина задаётся
  полем `depth` у ряда (по умолчанию 3, у топ-рейтинга/новинок 2), `rotate:false`
  выключает ротацию для узких рядов. Счётчик открытий хранится в
  `Storage('dorama_open_seq')`.
- **Скорость загрузки** — `ROW_CONCURRENCY` (по умолчанию 4) — сколько рядов
  грузится параллельно; при ошибках 429 от прокси TMDB снизьте до 3.
- **Скрытие контента (BL / gay)** — все ряды каталога идут с
  `without_keywords=<BL_KEYWORDS>` (boys' love, lgbt, gay, homosexuality и т.п.),
  а лента рекомендаций дополнительно исключает такие тайтлы по id (`buildBLBlock`,
  т.к. `/recommendations` не принимает `without_keywords`). Чтобы изменить набор —
  правьте константу `BL_KEYWORDS` в `dorama.js` (id ключевых слов TMDB).
- **Настроить рекомендации** — берётся до 8 последних позитивных сигналов
  (`collectSignals().positives.slice(0, 8)`); веса в `scoreCandidate`
  (совпадение между лайками / жанр / язык / рейтинг) и формула `predictionPercent`
  определяют «процент совпадения». Жёсткие фильтры «только азиатское» и
  «обязательное совпадение жанров» — в цикле `finish()` внутри
  `loadRecommendations`.

## Совместимость

Чистый ES5, зависит только от глобального `Lampa` и `$` (jQuery из Lampa).
Никаких внешних запросов, кроме TMDB (через встроенный источник `tmdb`).

### broadcast.js — «На ТВ» (Play on TV)

Добавляет кнопку «На ТВ» на каждую страницу деталей фильма/сериала.
Использует встроенный модуль `Broadcast` Lampa: нажмите → выберите устройство →
страница деталей откроется на нём, готовая к воспроизведению.

Работает через облачный сокет аккаунта (wss, cub-зеркала), поэтому общая
Wi-Fi-сеть **не требуется**: в списке видны все устройства, где выполнен вход
в тот же аккаунт и Lampa сейчас открыта — хоть в другом городе.
Кнопка скрывается на версиях Lampa без `Broadcast`, в режиме «дети» и без
входа в аккаунт (без логина список устройств всегда пуст).

Плагин использует собственное окно выбора устройств (тот же протокол и вид,
что у родного Broadcast) с дополнительными возможностями:

- **✎ у каждого устройства** — переименовать его: новое имя отправляется
  устройству по сокету (применяется для всех, если на нём тоже установлен
  этот плагин) и сохраняется локальным псевдонимом (видно здесь сразу в любом
  случае). Имена экранируются — чужое устройство не может внедрить HTML.
- **Нижняя строка «✎ Переименовать это устройство»** — меняет `device_name`
  текущего устройства (имя, которое видят все остальные).

Дубли вроде двух «Browser - Lampa» — это две живые сессии (две вкладки);
после переименования их легко различить.

### kazakh.js — «Казахское кино»

Тот же принцип, что у «Дорамы», для кино и сериалов Казахстана: пункт
**«Казахское кино»** в левом меню открывает живую ленту из TMDB с персональными
рекомендациями по вашим лайкам.

```
https://drshpackz.github.io/dorama/kazakh.js
```

Сверху вниз: **Рекомендации для Вас** (с бейджем «xx%») → Сейчас смотрят,
Казахские сериалы, Самые популярные фильмы, Новинки (закреплены) → жанры
(комедии, боевики и криминал, триллеры, драмы, историческое и военное, ужасы,
мелодрамы, семейное и мультфильмы, на казахском языке, документальное) →
Лучшее казахское кино, Классика «Казахфильма», «Казахфильм»: современное кино,
Фильмы Акана Сатаева, Адильхан Ержанов, Бизнес по-казахски (Нурлан Коянбаев),
Народные комедии (Nurtas, 567 Cinema), Salem: кино и веб-сериалы. Жанровые и
студийные ряды сортируются по вашему вкусу, как в «Дораме».

Чем отличается от «Дорамы» — всё из-за того, что казахский каталог на TMDB
маленький (замер 2026-09-11: ~1300 фильмов и 62 сериала с `origin_country=KZ`,
из них только ~40 фильмов с 10+ голосами):

- **Ряды фильтруются по стране, а не по языку** — `with_origin_country=KZ`.
  Большая часть казахского кино снята на русском; ряд «На казахском языке»
  (`with_original_language=kk`) — отдельный.
- **Отбор по постеру, а не по голосам.** Порог голосов опущен до 0–2, зато
  карточки без постера выкидываются из каждого ряда (их около трети).
- **Ротация только там, где есть глубина** (`depth` у ряда). Если повёрнутая
  страница короче 6 карточек, ряд берёт первую страницу — у тонкого пула вторая
  страница часто огрызок.
- **Повторы разнесены по ленте.** Одни и те же хиты (Хакер, Томирис, Рэкетир)
  попадают в половину жанров; уже показанные выше тайтлы уходят в конец
  следующих рядов, так что каждый ряд начинается с нового. Ничего не удаляется.
- **Рекомендации только казахские.** Карточки каталога помечаются
  `origin_country: ['KZ']` — Lampa сохраняет это поле в избранном, поэтому лайк,
  поставленный здесь, узнаётся потом. Лайки не-казахских фильмов из остальной
  Lampa в рекомендации не идут. Реакции без карточки проверяются по деталям
  TMDB (страна производства). Собственные рекомендации TMDB для казахского фильма
  — в основном русское и голливудское кино, поэтому основу ряда дают
  discover-запросы по стране + ваши жанры и студии.
- **Shorts нет**: в ленте CUB Shots казахских роликов практически нет.
- **Фильтр BL/gay** — те же `without_keywords`, что в «Дораме»; отдельной
  блокировки по id для рекомендаций нет, потому что на TMDB нет ни одного
  казахского тайтла с этими ключевыми словами (проверено).

Если стоят оба плагина, бейдж «xx%» не рисуется дважды: оба используют класс
`dorama-match` и пропускают карточку, где он уже есть.

### multi-fan.js — «Multi-Fan»: мультфильмы по каналам, 12+ и 18+

```
https://drshpackz.github.io/dorama/multi-fan.js
```

Пункт **Multi-Fan** в левом меню. Сверху — ряд прямоугольных плиток:
**Все мульты · 18+ · Adult Swim · Cartoon Network · FOX · Comedy Central · MTV ·
TBS · Netflix · Hulu**. Это два фильтра: **канал** и **возраст**. «Все мульты»
снимает канал, «18+» переключает возраст, логотип выбирает канал.

**Детского нет.** По умолчанию всё — 12+ и старше; «18+» — только для взрослых.
Возраст берётся из рейтингов TMDB. Фильтр в рядах идёт по американской шкале:
она заполнена намного чаще российской (325 мультсериалов против 92 на границе
12+). Граница сверена с российскими рейтингами тех же тайтлов:

| | 12+ | 18+ |
|---|---|---|
| сериалы | TV-PG и старше (Время приключений, Дарья, Вселенная Стивена — у них RU 12+; TV-Y7 и TV-G — это 6+ и 0+) | TV-MA |
| фильмы | PG-13 и старше (PG — это RU 6+: Шрек, Головоломка) | R, NC-17 |

Нет американского рейтинга — решает российский (12+/18+); нет никакого — тайтл
не показывается. Из-за этого ушли ряды студий и «Семейные мультфильмы» (у Pixar,
Disney и DreamWorks нет ни одного фильма PG-13) и **Disney Channel** — без
детских мультсериалов у него остаётся два. В 18+ показываются только каналы, где
взрослого хватает на страницу (3+ тайтла): Adult Swim, FOX, Comedy Central,
Netflix, Hulu. «Продолжить просмотр» тоже фильтруется по возрасту.

- **Канал не выбран** — весь каталог: популярные и новые мультсериалы и
  мультфильмы, по ряду на каждый канал («Ещё» открывает канал), лучшие.
- **Канал выбран** — только его мультсериалы: «Главное на канале» (подборка,
  см. ниже), популярное, новое, лучшее, классика. Ряды, которые у маленького
  канала повторяют уже показанное, убираются. Пульт сразу стоит на первом
  сериале.
- Со стартовой страницы (все каналы, 12+) фильтр открывает новую страницу
  («Назад» — на старт); дальше переключения заменяют страницу, чтобы «Назад» не
  проходил через все просмотренные фильтры.

**Модель, а не кнопки.** Каналы — это данные (`NETWORKS` в `multi-fan.js`):
id сетей TMDB (`tmdb`), подборка мультсериалов (`series`, id TMDB, в порядке
показа) и возрасты, на которых канал показывается (`ages`). Плитки, ряды и
фильтр «Продолжить просмотр» читают модель через `networksOf()` /
`networksFor()`. Подборка важнее TMDB: «Фионна и Кейк» на TMDB — Max, «Побочные
квесты» — Hulu, а здесь они там, где их ищут фанаты (Adult Swim, Cartoon Network).
Один мультсериал может быть в нескольких каналах (Футурама: FOX, Comedy Central,
Hulu). Все сериалы подборки — 12+ по правилу выше (проверено по TMDB); детские
(Вся правда о медведях, Мы маленькие медведи, Гамбол, Суперкрошки…) убраны.
Подборку дополняет всё остальное, что TMDB числит за каналом; сериал из подборки,
которого нет в списке TMDB, подтягивается по id вместе с рейтингом и кешируется.

**Продолжить просмотр** — постер и подпись «Сезон 2 · Серия 5 · 12:34» с
полоской прогресса; у фильма «43:30 из 1:27:00». Берётся из `Timeline` самой
Lampa: для каждой серии там хранится прогресс и время последнего изменения,
поэтому показывается серия, которую смотрели **последней**, а не с самым
большим номером. Досмотренная серия (90%+) передаёт место следующей («Сезон 3 ·
Серия 1 · с начала»), досмотренный финал убирает сериал из ряда. На странице
канала — только его сериалы. Сезоны, сети и рейтинг берутся из деталей TMDB и
кешируются на 3 дня одной записью в Storage.

Только западная анимация: аниме-тег исключён везде, ряды каталога ограничены
странами (`with_origin_country`), японские/корейские/китайские оригиналы,
попавшие в список канала, отбрасываются.
